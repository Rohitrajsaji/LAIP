# Retained runtime dependency notices

These files are copied byte-for-byte from locally installed dependencies matching the locked versions on 9 October 2026. Package names are sanitized in directories; original relative paths and SHA-256 hashes are recorded in [the dependency inventory](../../packaging/dependencies.json).

`python/` contains distribution license files. `npm/` contains package and bundled/vendor license files, plus separately identified supporting READMEs/version metadata for packages without standalone notice files. Supporting files are not counted as legal notices.

See [dependency notices](../../dependency-notices.md) for coverage, exclusions and unresolved distribution gates. This collection is not a final-image SBOM, complete license clearance, or a license for LAIP itself.
